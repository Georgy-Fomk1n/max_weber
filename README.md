# Сайт-доклад: Легитимное государство и теория рациональной бюрократии М. Вебера

Современный информационный сайт-доклад по социологии Макса Вебера, созданный с соблюдением бренд-гайдов Финансового университета.

## Особенности

- **Минималистичный академичный дизайн** в стиле университетского исследовательского проекта
- **Цветовая система Финансового университета** (`#256569` - фирменный акцент)
- **Светлая и тёмная тема** с переключателем
- **Интерактивные схемы** для визуализации социологических концепций
- **Адаптивный дизайн** для всех устройств
- **Плавные анимации** при скролле и наведении

## Технологический стек

- **Vite** - быстрый сборщик для статических сайтов
- **Vanilla JS** - нативный JavaScript без фреймворков
- **CSS Variables** - для управления темами
- **Inter** - современный гротеск от Google Fonts

## Структура сайта

Сайт состоит из четырёх основных секций:

1. **Введение** - Понятие легитимности в социологии М. Вебера
2. **Государство** - Легитимное государство в концепции М. Вебера
3. **Бюрократия** - Теория рациональной бюрократии М. Вебера
4. **Заключение** - Рационально-легальное господство и современное управление

## Разработка

### Установка зависимостей

```bash
npm install
```

### Запуск локального сервера

```bash
npm run dev
```

Сайт будет доступен по адресу `http://localhost:5173/weber-site/`

### Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут находиться в папке `dist/`

## Размещение на GitHub Pages

### Автоматический деплой через GitHub Actions

1. Создайте репозиторий на GitHub
2. Загрузите файлы проекта в репозиторий
3. Создайте файл `.github/workflows/deploy.yml`:

```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches: [ main ]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: "pages"
  cancel-in-progress: false

jobs:
  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4
      - name: Setup Node
        uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'
      - name: Install dependencies
        run: npm ci
      - name: Build
        run: npm run build
      - name: Upload artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: './dist'
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```

4. В настройках репозитория:
   - Settings → Pages → Source выберите "GitHub Actions"
   - Убедитесь, что Pages включены

### Ручной деплой

1. Соберите проект: `npm run build`
2. Загрузите содержимое папки `dist/` в ветку `gh-pages`
3. В настройках репозитория выберите ветку `gh-pages` как source для Pages

## Кастомизация

### Изменение цветовой схемы

Цвета задаются в `src/main.css` в секции `:root`:

```css
:root {
  --accent-color: #256569;  /* Фирменный цвет Финансового университета */
  /* другие цвета... */
}
```

### Добавление нового контента

Для добавления нового контента:

1. Добавьте новую секцию в `index.html`
2. Добавьте соответствующие стили в `src/main.css`
3. Обновите навигацию при необходимости
